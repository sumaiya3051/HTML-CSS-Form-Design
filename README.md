
# 🌊 Ocean Breeze – Login & Registration Forms

A clean, modern, and responsive Login and Registration Form website developed using HTML5 and CSS3.

## 📌 Project Overview

This project is created as part of a Web Technologies assignment. It provides a simple and user-friendly interface for users to log in or create a new account.

## ✨ Features

### Login Form
- Email input field
- Password input field
- Required field validation
- Link to Registration Form

### Registration Form
- Full Name and Email fields
- Password and Phone Number fields
- Date of Birth
- Country dropdown menu
- Gender selection using radio buttons
- Multiple Interests using checkboxes
- Address and About Yourself text areas
- Terms and Conditions checkbox
- Submit and Reset buttons

## 🛠️ Technologies Used

- HTML5
- CSS3
- Visual Studio Code
- Git and GitHub

## 🎨 Design

- Ocean Breeze color theme
- Minimal and elegant interface
- Responsive layout
- Soft colors and rounded cards
- Hover and focus effects

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using Live Server.
4. Navigate between Login and Registration pages.
